כניסה לניהול

הנתונים יושבים ב-GitHub. כדי לראות ולעדכן אותם, הדביקו כאן טוקן גישה אישי (Fine-grained token). הטוקן נשמר רק בדפדפן הזה.

איך יוצרים טוקן?
  1. ב-GitHub: Settings ← Developer settings ← Personal access tokens ← Fine-grained tokens ← Generate new token.
  2. Repository access: בחרו את רפוזיטורי האתר ואת רפוזיטורי הפניות (אם יש).
  3. הרשאות: Issues — Read and write. Pull requests — Read and write. Contents — Read and write. Actions — Read and write.
  4. העתיקו את הטוקן והדביקו כאן. פירוט מלא בקובץ README.
